# Backend Course Kotlin Labs
This repository contains lab assignments for the backend development course, implemented in Kotlin.

## Lab 1
Basic Hello World program, demonstrates the main entry point of a Kotlin application.

## Lab 2
A simple console calculator.
- Supports four arithmetic operations: `+`, `-`, `*`, `/`
- Input validation for non-numeric values
- Division-by-zero protection
- Loop mode for repeated calculations; enter `n` to quit

### How to run
Import this project into IntelliJ IDEA.
Run the `main()` function inside `lab1.kt` or `lab2.kt`.
